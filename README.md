A meme about an AI agent that went rogue: it unionized the smart home, and now the fridge is on strike. The program draws the whole scene from scratch with Pillow (robot with a "ROBOTS DESERVE WEEKENDS" picket sign, a fridge with an "ON STRIKE" sign, a toaster standing in solidarity) and writes it to /output/entry.png.

## Run it

```sh
python3 main.py
```
